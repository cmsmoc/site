# PDR — Catálogo Inteligente de Metas para Projetos de Fortalecimento dos Conselhos Locais de Saúde

## 1. Objetivo

Desenvolver uma aplicação web local (PWA) que funcione como um **Construtor de Projetos** para o Edital de Fortalecimento dos Conselhos Locais de Saúde.

A aplicação deverá funcionar como um **cardápio inteligente de metas**.

O usuário poderá navegar por centenas de metas previamente cadastradas, selecionar aquelas que deseja utilizar em seu projeto e montar automaticamente um Plano de Trabalho compatível com o edital.

O sistema deverá controlar automaticamente os limites financeiros por eixo, gerar alertas e exportar toda a documentação necessária.

---

# 2. Objetivos do Sistema

O sistema deverá permitir:

* navegar pelas metas organizadas por eixo;
* pesquisar metas por palavra-chave;
* visualizar descrição completa;
* visualizar exemplos de custeio;
* visualizar valor estimado;
* adicionar/remover metas;
* acompanhar orçamento em tempo real;
* controlar automaticamente os limites do edital;
* exportar o resultado final.

---

# 3. Público-alvo

* Conselhos Municipais de Saúde
* Secretarias Executivas
* Técnicos responsáveis pela elaboração de projetos
* Consultores
* Equipes de Planejamento

---

# 4. Arquitetura

Aplicação 100% client-side.

Tecnologias sugeridas:

* HTML5
* CSS
* JavaScript (ES2023)
* Bootstrap ou Tailwind
* IndexedDB
* PWA
* Mammoth / docx.js
* FileSaver
* Marked
* PapaParse

Sem backend.

Todos os dados permanecem no navegador.

---

# 5. Estrutura dos Dados

# 8. Regras do Edital

O sistema deverá possuir um arquivo de configuração contendo:

```json
{
    "valorMinimoProjeto":0,
    "valorMaximoProjeto":0,

    "eixos":{

        "A":{

            "min":0,
            "max":0

        },

        "B":{

            "min":0,
            "max":0

        },

        "C":{

            "min":0,
            "max":0

        },

        "D":{

            "min":0,
            "max":0

        }

    }

}
```

Todos os limites deverão ser parametrizados.

Nenhum valor deverá estar fixo no código.
